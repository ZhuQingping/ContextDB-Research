# 华为云 ContextDB 差异化竞争力

版本：1.0｜日期：2026-10-08｜用途：产品决策与开发交付

> 本文是2026-10-08的候选能力规划，未获当前产品范围整体批准。当前首期选择为独享版；文中的共享Cell、多Cell及P0/P1顺序均为当时建议。竞争力主张须通过文内验收并结合最新产品决策后才能对外使用。

领导可先读第 1–3 节；开发者继续读第 4–7 节。证据编号对应 [证据与决策记录](ContextDB竞争力证据与决策记录.md)，其中保存来源、验证状态和结论变化。

## 1. 先做什么、为什么

建议优先交付 **数据加密存储、记忆与知识导出、中文场景优化**，配套权限、操作审计和恢复演练。

- **加密存储**：让客户清楚会话、知识、附件和备份如何保护，是企业采购基础。
- **记忆与知识导出**：客户能拿走自己的数据；对阿里现有导出限制有具体对照，是当前较直接的差异。
- **中文优化**：既能找准中文术语，也能正确处理否定、人员变化、时间和金额。优势必须用效果测试证明。

当前结论是产品规划，不代表全部已实现。加密不是华为独占；可导出不自动等于可迁移；使用中文向量模型不自动等于中文记忆理解正确。底座已有能力、产品需开发的部分和效果测试分别验收。[EV-001–EV-009、DEC-001–DEC-004]

## 2. 具体能力总览

“底座支持”表示 RDS/Hindsight 有能力；“拟开发”表示 ContextDB 还需接入或新增；“待实测”表示没有效果报告。P0/P1 是顺序，不是交期承诺。能力编号沿用旧清单，方便追溯。

| 编号 | 客户能做什么 | 客户价值 | 当前状态 | 定位/顺序 |
|---|---|---|---|---|
| A1 | 查看数据库、附件、备份、导出包的加密覆盖 | 保护会话和组织知识 | RDS 底座支持，产品开通/检查拟开发 | 基础能力，P0 |
| A2 | 独享版选客户管理密钥，查看授权状态 | 掌控密钥权限 | 自定义密钥底座支持，跨账号/恢复待验 | 企业选配，P1 |
| D1 | 导出 Bank/知识库或 Workspace 资产包 | 留存、审计、离云、迁移 | 部分上游接口已有，全量/快照拟开发 | 直接差异候选，P0 |
| B1 | 用中文关键词和语义共同检索 | 找准人名和术语 | zhparser 底座支持，读写适配/历史重建拟开发 | 效果待测，P0 |
| B2 | 配企业术语、简称和别名 | 减少漏检与错配 | 词表与查询扩展拟开发 | 候选差异，P1 |
| B3 | 验证中文否定、更新、时间、身份、金额 | 正确记住事实变化 | 当前部署有中文 embedding，端到端待测 | 质量门禁，P0 |
| A3 | 按 Workspace/Bank/知识库授权，单独控制导出 | 控制 Agent 共享范围 | 上游扩展点有，云产品 ACL 需完善 | 基础能力，P0 |
| A4 | 查写入、查询、修改、删除、导出的成员/Key | 追查修改和下载 | 业务审计拟开发 | 基础能力，P0 |
| C1 | 在保留窗口内找回误删数据 | 数据资产可恢复 | 实例备份可复用，租户提取/附件对齐拟开发 | P0 演练/P1 自助 |
| D2 | 查看来源，纠正记忆并保留修改历史 | 判断依据、修正错误 | 来源引用有，完整血缘/人工保护拟开发 | 候选差异，P1 |
| D3 | 开启推断确认，拒绝后不重复注入 | 防止未经确认的推断影响回答 | 有竞品先例，状态与全链路过滤拟开发 | 治理增强，P1 |
| D4 | 按主体删除，取得执行范围与回执 | 离职、撤权、敏感清理 | Cloud 有先例，开源与派生清理待验 | 治理增强，P1 |

依据：[EV-001–EV-015]；详细实现状态见机器文档的 capabilities。主体指关联到某用户或人员的数据，不只是删除一个数据库行。

下表是已有调研材料的归纳，未在本轮合并时重新抓取所有官网。具体限制需在发布前复核；不能用“未见声明”代替“没有能力”。

| 对照对象 | 需要承认的已有能力 | 我方具体投入 |

| 阿里 ContextDB | 记忆沉淀、晋升审批、知识评审、知识同步与 CLI/MCP 接入 | 导出完整资产包；权限、来源和记忆纠错。其导出限制目前有官方搜索索引支持，正文快照待复核 |
| 火山 OpenViking Context | Memory/Resource/Skill 统一、分层检索、托管与生态接入；原报告有企业独占实例 | 提供透明开源/云差异表，验收数据库恢复、区域链路与成本。不能称其企业版全共享 |

| AWS AgentCore Memory | 短/长期记忆、策略抽取、客户密钥、事件与记录 API | 说明加密覆盖、抽取策略及成本；metadata 的客户密钥限制不等于完全不加密 |

依据：[EV-010–EV-019、EV-026–EV-030]。

## 4. 三项主打能力的交付要求

### 4.1 数据加密存储

验收后可表述：**记忆与知识数据库采用存储层加密，附件、备份和导出文件按各自策略保护，可查看覆盖与密钥状态。**

| 数据位置 | 必须做什么 | 怎么验收 |
|---|---|---|
| DataPG：正文、元数据、向量/全文/关系索引 | Cell 开通时启用磁盘加密，核查主库和只读实例 | 配置、密钥标识、落点清单 |
| MetaPG：租户配置与凭据相关数据 | 独立配置保护，凭据存储单独设计 | 不保存完整 API Key 明文，配置检查 |
| OBS：原文、附件、导出包 | 对象加密、授权、临时链接、过期清理 | 越权下载失败，检查对象状态和清理 |
| 数据库备份 | 核实目标 PG 区域/版本与密钥依赖 | 实际备份恢复成功并记录条件 |
| 日志、缓存 | 默认不记正文和完整凭据，必要落盘内容另保护 | 脱敏抽样、保留策略检查 |

RDS PG 官方已列磁盘加密和 AES_256/SM4；算法可用不等于 ContextDB 已通过密评。静态加密不代表授权访问和模型推理看不到明文。[EV-001、EV-002]

独享版客户管理密钥（CMK）与导入客户密钥材料（BYOK）分开承诺。当前共享 Cell 的卷密钥按实例生效；客户独立卷密钥优先用独享 Cell。禁用密钥不等于缓存、副本和备份立即销毁。[EV-003、EV-007、DEC-005]

演示用一条中文记忆、一份知识文档和附件，逐个检查落点，做越权下载与备份恢复。API 可读不能证明加密有效。备份默认行为仍按目标实例核实，不套用 MySQL 口径。[EV-002、EV-003]

### 4.2 记忆与知识导出

验收后可表述：**按范围导出公开格式的记忆与知识资产包，附来源与完整性校验。** 导入及引用恢复通过后再宣传可迁移。[EV-004、EV-008、DEC-003]

| 对象 | 导出内容 | 验收 |
|---|---|---|
| 记忆 | 正文、类型、标签、时间、来源；派生观察明确覆盖范围 | 按类型对条数、字段、引用 |
| 知识 | 原文/附件、条目或页面、来源、状态；版本/关系按合同列明 | 文件校验和一致，无遗漏 |
| 恢复配置 | Bank/知识库配置、模型/格式版本、ID 映射 | 空 Workspace 重建，引用正确 |
| 权限 | 受控权限映射说明，不导出密钥秘密 | 导入后重新授权，旧 Key 不复用 |
| 清单 | manifest.json：范围、快照时间、格式版本、数量、SHA-256、未支持项 | 独立工具查缺件与损坏 |

推荐记忆 JSONL、知识文本 Markdown/JSON、附件原格式，发布 schema。向量可声明为重建项，注明模型与费用。资产包与数据库无损备份分别定义。

必须补齐完整遍历、稳定分页、并发写入快照、异步任务、重试、权限/审计、大文件交付、过期清理、版本兼容。recall 只返回相关内容，不能充当全量导出。

建议用 1 万条记忆、100 份知识文档及附件作为测试起点，覆盖中文、空值、重名和关联引用；并发写入下核对快照，导入空 Workspace 后核对内容、引用、权限与固定查询。这些数量是测试设计，不是容量承诺。

### 4.3 中文场景优化

验收后可表述：**优化中文连续文本、术语、中英混写与事实更新，提供固定数据集效果报告。**

RDS 已支持 zhparser；当前本地 PG 路径用 english，bge-m3 是本地部署选择。要验证目标插件版本和上游配置入口，统一全文写入/查询配置，重建历史 search_vector。只改查询端不够。[EV-005、EV-006、EV-009]

| 场景 | 示例 | 正确行为 | 指标 |
|---|---|---|---|
| 连续中文 | “张三负责华北数据库迁移”→“张三负责什么” | 按中文词匹配 | 关键词 Recall@10、混合 nDCG@10 |
| 术语/别名 | PG/PostgreSQL、主备切换/failover | 在企业词表范围内关联 | 术语召回、误召回率 |
| 否定/纠正 | “我不再负责 A，改由李四负责” | 当前用新负责人，历史保留旧事实 | 更新准确率、过时事实误用率 |
| 人名/组织 | 不同部门都有张伟 | 按身份区分，不强行合并 | 误合并率、越权命中 |
| 时间/金额 | “下周一上线”“预算 1.5 万” | 结合会话时间/时区，保留单位 | 时间/金额抽取准确率 |
| 跨会话/拒答 | 上次故障方案；未记录的采购价 | 引用来源，无依据不编造 | 回答正确率、无依据作答、引用正确率 |

词典定制未确认时先用外层术语映射。否定、时间和事实更新涉及抽取、巩固与回答，不能只装分词插件。

固定同一语料、至少 200 条人工标注 query、commit、各模型、预算、硬件，比较 english+向量与中文分词+同向量配置；别名和模型变化另做实验。分层报告召回、排序、回答/更新正确率、p95/p99、成本、样本和置信区间。自建集先做质量门禁，公开时给采样/标注/脚本，不称行业标准，不继承上游英文成绩。[EV-020、EV-021、DEC-004]

## 5. 配套能力与开发边界

| 能力 | 最小验收 | 容易漏掉的边界 |
|---|---|---|
| A3 权限 | 两租户同名 Bank；只读 Key 写入失败；recall/reflect/导出/附件验证 ACL | 对象前缀不等于权限，独立 PG 不等于网络/计算全独享 |
| A4 审计 | 两把 Key 写入/查询/删除/导出，以 request_id 查操作者/范围/结果/时间 | SQL 账号不等于用户，CTS 不自动覆盖业务 API |
| C1 恢复 | 隔离实例恢复后提取 Workspace，核对附件/后续写入 | 限保留窗口；实例 PITR 不等于单租户回滚，重放主体删除清单防复活 |
| D2 来源/纠正 | 观察可跳源文，人工纠正再巩固后仍受保护 | 引用不等于完整版本历史 |
| D3 确认/抑制 | 未确认在 recall/reflect/组合查询不可见，确认后可见，拒绝不反复注入 | 请求级校验不能代替候选过滤和后台治理 |
| D4 主体删除 | 源文、派生结果、附件清理，任务不能再生成 | 回执列范围、遗漏、完成时间、备份期限，不承诺即时全介质擦除 |

依据：[EV-007、EV-011、EV-012、EV-014、EV-015、DEC-006–DEC-009]。

RDS/OBS 负责基础存储与恢复，Gateway/控制面负责授权、导出任务、审计和计量；Extension 负责租户/Bank 操作边界。中文读写、治理候选及后台处理须验证扩展点，必要时做小范围适配，不预先承诺全部不改内核。模型网关负责模型端点地域、用量及额度。[EV-013、DEC-009]

## 6. 值得保留的后续投入

| 方向 | 具体内容 | 前置条件 |
|---|---|---|
| 记忆参与知识检索 | 用有权限的个人/团队记忆改写问题、影响排序，沿用组合 context/query | 不扩大权限，外层改写先验证，深入 rerank 单独评估 |
| 知识运营 | 来源标注、人工版本保护、FAQ 反例、解析时间线/卡住检测、评估 API | WeKnora 有先例，优先治理和质量反馈，不重做整套 Wiki |
| 巩固可观测 | 展示后台 consolidation 消耗、产出、调度及可测收益 | 抽取/巩固费用归属，产出可溯 |
| 时序/关联检索 | 事实失效与历史追踪；PG 实体图上的 PPR 多跳 | 研究方案，不是已有新增功能；逐项测正确率/成本 |
| 知识摘要与记忆包 | 分层摘要、MemCube 式资产迁移、动态笔记关联 | 保留研究候选，不进入首期硬承诺 |
| 地域/私网/多 Cell | 私网入口、区域链路、扩 Cell、主备/Worker 恢复 | PG/OBS/备份/模型都核查，端到端 SLA 另定 |
| 读副本/冷归档 | 副本检索；先归档原文附件 | 写副作用、复制延迟、回源费及召回影响 |
| MCP/SDK/协议 | 租户端点、只读工具、scoped token；Claude 六命令后端适配 | 按客户端版本验收；路径安全与权限，不能仅把命令映射成 Bank |
| 成本/配额 | Workspace/Bank 拆三操作、后台 token 与存储 | 计量闭环和超额行为；成本可解释，不保证最低价 |
| 生态与开源 | 发布开源/云能力差异表，评估 CodeArts/ModelArts 等接入，上游贡献 | 清楚标复用与新增；不把许可证当性能优势 |

研究输入保留 MemGPT、Mem0、A-MEM、MemOS、Zep、HippoRAG/2、RAPTOR、Generative Agents、Sleep-time Compute、Hindsight 及评测基准的机制/数字/原始链接，详见机器文档与原文归档。[EV-016–EV-030]

商业模式建议按存储/调用和模型 token 说明费用，区分托管抽取、自带模型、自管线；评估免费额度、订阅捆绑和独享 SKU。原调研价格是历史快照，具体数字保存在机器记录，不能直接充当当前报价。Letta 转型提醒需评估独立变现风险，不能由一家转型推断记忆服务无法商业化。[EV-017–EV-019、EV-026–EV-028、DEC-012]

当前不优先重做 IM 渠道、桌面/浏览器产品、技能沙箱和 Agent 运行时，也不因图检索直接引入第二图引擎。数据源同步、引擎选配、国产化/信创与密评按实际需求和证据另立项，不作已具备的宣传。[DEC-010、DEC-013]

## 7. 交付顺序与发布条件

| 阶段 | 工作 | 阶段出口 |
|---|---|---|
| 依赖验证 | 实例插件、加密/备份、全量 API、权限/删除关系 | 兼容报告、覆盖清单、缺口/负责人 |

| 增强 | 导入迁移、CMK、主体删除、来源/纠正、确认/抑制 | 迁移、密钥恢复、删除回执、治理报告 |
