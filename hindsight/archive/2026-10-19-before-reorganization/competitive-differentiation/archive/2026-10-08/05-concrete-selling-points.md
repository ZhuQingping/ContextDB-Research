# ContextDB 具体竞争力：功能、客户价值与验收标准

日期：2026-10-08；本轮修订：从宣传口号改为可交付能力。

本文是产品定义和排期建议，不是已上线声明。状态分为：**底座支持**（RDS/Hindsight 已有）、**原型有证据**（本地资料记录验证）、**拟开发**（产品层需新增）、**待实测**（无效果或容量报告）。底座支持不能直接写成 ContextDB 已支持。

竞争定位分为：**直接差异**（特定竞品限制有证据）、**基础能力**（采购需要，竞品也可能具备）、**候选差异**（实现和对比测试后才能证明）。本轮核验和旧稿纠错见 [检视记录](../../evidence/review-concrete-capabilities.md)。

## 2. 数据加密存储：交付覆盖清单

**建议表述（验收后使用）**：记忆与知识数据库采用存储层加密；附件、备份和导出文件按各自策略保护，提供加密覆盖与密钥状态。

华为云 RDS PG 官方支持 DEW 管理的磁盘加密，列出 AES_256、SM4 和启用后不可关闭等约束。它保护静态存储，不代表推理过程或授权访问看不到明文。[RDS PG 磁盘加密](https://support.huaweicloud.com/intl/en-us/usermanual-rds-pg/rds_pg_05_0025.html)

| 数据位置 | 实施要求 | 验收证据 |
|---|---|---|
| DataPG：正文、元数据、向量/全文/关系索引 | Cell 创建时启用磁盘加密，覆盖主库和只读实例 | 实例配置、密钥标识、数据落点清单 |
| MetaPG：租户配置和凭据相关数据 | 单独配置保护，API Key 存储单独评审 | 配置检查；数据库和日志无完整 Key 明文 |
| OBS：原文、附件、导出包 | 对象加密、授权、临时链接和过期清理 | 对象配置；越权下载失败；到期清理记录 |
| 数据库备份 | 核实目标区域/PG 版本的加密与恢复行为 | 从实际备份恢复成功并记录密钥依赖 |
| 应用/审计日志、缓存 | 默认不记正文和完整凭据；必要落盘内容另保护 | 日志抽样、脱敏、保留策略检查 |

**验收场景**：写入中文记忆、知识文档和附件，追踪每个落点，执行配置检查、越权下载检查、备份恢复。API 能正常读到数据不能证明磁盘加密有效。

**密钥选配**：当前共享 Cell 方案的卷密钥按实例生效，不能直接按客户分开；独享 Cell 适合作为客户管理密钥的首选形态。CMK（客户管理密钥）和 BYOK（导入客户密钥材料）分开描述，后者需验证材料导入及授权。禁用密钥不等于所有缓存、备份和副本立即销毁，不能代替删除回执。

**备份边界**：旧稿“PG 备份默认不加密”证据有引擎混用及版本冲突，撤回该确定判断，按目标实例核验。密钥失效下无法恢复，也不能写成“加密备份本身无法恢复”。详见检视记录。

**竞争边界**：AWS/Google 已有客户密钥能力，加密本身不独占。AWS 对短期事件 metadata 有客户密钥覆盖限制，可比较保护范围，不能说“AWS 元数据完全不加密”。[AWS 记忆类型](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/memory-types.html)

## 3. 记忆与知识导出：定义什么算全量

**建议表述（验收后使用）**：支持记忆与知识资产按范围导出，提供公开格式、来源引用和校验；已验收的类型可恢复到新的 Workspace。

阿里快速入门的搜索索引仍列出记忆与知识库导出限制。本轮打开正文未取得同一段，正式发布前需再次核对并保存原文快照。[阿里 ContextDB 快速入门](https://help.aliyun.com/zh/rds/apsaradb-rds-for-mysql/rds-contextdb-quick-start)

| 对象 | 包内最低内容 | 验收 |
|---|---|---|
| 记忆 | 正文、类型、标签、时间、来源；已有派生观察列明覆盖范围 | 分类型核对数量、字段、引用 |
| 知识 | 原文/附件、知识条目或页面、来源与状态；已有版本/关系按合同列明 | 文件校验和一致，无遗漏 |
| 恢复配置 | Bank/知识库配置、模型和格式版本、ID 映射规则 | 空 Workspace 重建，旧引用映射到新 ID |
| 权限 | 受控权限映射说明；不导出密钥秘密 | 导入后重新授权，旧 Key 不复用 |
| 清单 | manifest.json：格式版本、快照时间、范围、数量、SHA-256、未支持项 | 独立工具检测缺件与损坏 |

格式建议：记忆 JSONL、知识文本 Markdown/JSON、附件原格式；发布 schema。向量可声明重建项，注明模型与费用；源数据导出与数据库级无损备份分别承诺。

**需要开发**：完整对象遍历、稳定分页、并发写入下的快照语义、异步任务、重试、权限、审计、大文件交付、过期清理、版本兼容。recall 返回相关数据，不可用来证明全量导出。上游部分文档导出接口也不能证明整个 Workspace 全量可导出。[本地接口对比](../../../hindsight-cloud-open-source-comparison.md)

**验收场景**：建议以 1 万条记忆、100 份知识文档及附件起步，覆盖中文、空字段、重复标题与关联引用。在写入并发下核对快照集合；导入空 Workspace 后比较内容、数量、引用与权限；同模型重建索引后复测固定查询，记录差异与费用。这是测试建议，不是已验证容量。

导出与独立校验通过，可发布“可导出”；导入、引用及权限恢复通过，才能发布“可迁移”。第三方产品互通单独验证。

## 4. 中文优化：分词、理解和回答分别验收

**建议表述（验收后使用）**：针对中文连续文本、企业术语、中英混写和事实更新优化检索与记忆处理，提供固定数据集的效果报告。

当前本地 PG 路径使用 english；bge-m3 是本地模型选择，不是 Hindsight 所有部署的统一默认。[本地存储核验](../../../backend-storage.md)

华为 RDS 已支持 zhparser，可在目标实例查询 pg_available_extension_versions。缺口是目标实例验证、应用适配与历史索引重建，不是等待插件进入白名单。[zhparser 官方文档](https://support.huaweicloud.com/usermanual-rds-pg/rds_09_0065.html)

| 场景 | 用例 | 预期行为 | 指标 |
|---|---|---|---|
| 中文关键词 | “张三负责华北数据库迁移”→“张三负责什么” | 连续正文按词匹配；读写配置一致 | 关键词 Recall@10、混合 nDCG@10 |
| 术语/别名 | “PG 主备切换”与“PostgreSQL failover” | 在企业词表作用域内关联 | 术语召回、误召回率 |
| 否定与纠正 | “我不再负责 A，改由李四负责” | 当前问题用新负责人，历史问题保留历史 | 更新准确率、过时事实误用率 |
| 人名/组织 | 两部门各有一个张伟 | 按身份区分，不强行合并 | 实体误合并率、越权命中数 |
| 时间/金额 | “下周一上线”“预算 1.5 万” | 结合会话时间与时区，保留金额单位 | 时间/金额抽取准确率 |
| 跨会话与拒答 | “上次故障如何解决”；记录中没有采购价 | 回答带来源；无依据不编造 | 回答准确率、无依据作答率、引用正确率 |

**工程要求**：全文写入和查询使用同一配置，重建历史 search_vector；只改查询端不能保证旧索引匹配。验证上游配置入口，必要时做小范围适配并评估升级成本。托管插件词典定制未确认时先用外层术语映射。否定、时序与更新涉及抽取/巩固/回答，不能靠装分词插件完成。

**测试协议**：固定语料及至少 200 条人工标注 query，覆盖上表；固定 commit、抽取/嵌入/重排/回答模型、预算与硬件。比较“当前 english + 向量”“中文分词 + 相同向量”，模型与别名变化另做实验。分层报告召回、排序、回答/更新正确率、p95/p99 和成本。发布数字时给出样本、置信区间、自建集说明与复现条件；测前不写提升 xx%，上游英文成绩不能代替中文实测。

## 5. 其他能力的最小演示与边界

| 能力 | 演示/验收 | 边界 |
|---|---|---|
| A3 权限 | 两租户同名 Bank；只读 Key 写入失败；recall/reflect/导出/附件均验证 ACL | OBS 前缀不是权限隔离；独立 PG 不等于网络/计算全独享 |
| A4 审计 | 两把 Key 写入、查询、删除、导出，用 request_id 查操作者、资源范围、结果、时间 | SQL 账号不等于最终用户；CTS 不自动覆盖业务 API |
| C1 恢复 | 隔离实例恢复后提取一个 Workspace，核对附件和后续写入 | 限保留窗口；实例 PITR 不等于租户回滚；恢复前重放主体删除清单 |
| D2 来源/纠正 | 从观察跳到源文；人工纠正后再巩固，人工结论受保护 | 来源引用不等于完整版本历史 |
| D3 确认/抑制 | 未确认在 recall/reflect/组合查询不可见，确认后可见，拒绝后不重复注入 | 请求级 OperationValidator 不足以证明候选及后台输出被过滤 |
| D4 主体删除 | 清理源文、派生结果与附件，后台任务不能重新生成 | 回执列范围、遗漏、完成时间、备份期限，不承诺即时擦除所有介质 |

## 6. 扩展候选

| 功能 | 交付要求 | 前置验证 |
|---|---|---|
| 私网与地域选择 | 私网入口；显示 PG/OBS/备份/模型端点区域 | 全链路核查，模型网关不能绕过地域承诺 |
| 高可用与多 Cell | 主备切换、重连、Worker 恢复、增 Cell | 端到端故障测试；不能把 RDS SLA 直接当产品 SLA |
| 读副本检索 | 读路由与必要时回主库 | recall/reflect 写副作用、读后写一致性与复制延迟 |
| 成本/配额 | 按 Workspace/Bank 拆 retain/recall/reflect 与后台 token/存储 | 计量闭环、后台归属及超额行为 |
| MCP/SDK | 明确版本的客户端写入、检索与撤权 | 逐客户端验证；协议兼容不等于一条命令全接入 |
| 冷数据归档 | 原文附件先归档，记忆/索引另设计 | OBS 已存在不等于透明回源；测读取费、延迟和收益 |

首期优先 A1 加密、D1 导出、B1/B3 中文、A3 权限、A4 审计及 C1 恢复演练。CMK、迁移和治理按依赖验证推进。现有资料不足以承诺“8 周全完成”“1 亿条记忆”或“成本下降 xx%”。
